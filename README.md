# agent-skills

个人 Agent Skills 集合（适用于支持 Agent Skills 的环境：Claude Code、Claude.ai 等）。

## 包含技能

| 技能 | 说明 |
|------|------|
| `dev-mentor` | **引导式开发**：AI 只辅助、不代写。进入教学前**先确认模式**（引导式教学 / 正常开发+讲解 / 纯正常开发），只有明确要求"自己写、别给我代码"才算开启教学；仅表现出学习动机时按正常开发处理。进入教学后随时说"**直接帮我修改 / 别教了 / 你来写**"即**立即退出教学**，改按正常开发整段交付、不设卡。教学模式内提供任务拆解 + 逐个引导 + 五维标准代码审查（正确性/可读性/健壮性/规范性/扩展性），严格批评、不奉承，帮用户亲手写出代码并积累经验 |
| `decision-challenge` | **反谄媚决策质询**：重要决策时用三阶段对抗质询（最强反方 → 最强正方 → 条件式辩证结论），对抗 LLM 的谄媚倾向（sycophancy）。辩论部分只留关键论据，**条件式辩证结论是输出主体且篇幅不短于辩论**，总篇幅按争议度自适应 |

## 安装

以 Claude Code 为例，把技能目录复制到 skills 目录：

```bash
# 个人级（所有项目可用）
mkdir -p ~/.claude/skills
cp -r skills/decision-challenge ~/.claude/skills/

# 或项目级（仅当前项目，随 git 共享给团队）
mkdir -p .claude/skills
cp -r skills/decision-challenge .claude/skills/
```

## 使用

安装后直接描述一个你**倾向做出的决定**即可自动触发，例如：

> 我倾向买 HD490 Pro 而不是 HD660S2 来听 ACG，因为……

技能会输出三阶段分析，**结论是主体**：

1. **反方质询**——最强立场证明你可能是错的（遗漏事实 / 过度乐观假设 / 不可逆成本 / 认知偏差），只留最有分量的 2–4 条
2. **正方辩护**——这个决定真正成立的最强理由（钢人论证），1–3 条
3. **条件式辩证结论**——裁决与置信度 + 什么条件下成立 + 什么条件下不成立 + 最重砝码 + 最大未知变量与反转条件 + 下一步先做什么（不和稀泥、不五五开）

篇幅按争议度分三档自适应：事实清楚的轻档约 250–350 字，常规取舍的中档约 450–600 字，高争议的重档约 700–900 字。铁律是**结论不短于辩论**，写不下就砍辩论。

