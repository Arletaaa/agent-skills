# 完整示例（渐进式披露）

> 本文件是 decision-challenge 的实战示例。SKILL.md 只保留核心规则；执行时若需要"完整输出长什么样"的参照，再读取本文件。
>
> 示例按"篇幅自适应"档位各给一个：**中档**（有真实取舍）、**轻档**（事实清楚、倾向与证据一致）。

## 示例一：HD490 Pro vs HD660S2 听 ACG（真实首测，中档）

**用户输入**：我倾向与 hd490pro 比 hd660s2 更适合听 acg，因为 hd660s2 是暖壶的频响曲线，不适合听人声，而 hd490pro 的解析强声场大。

**符合规范的输出**（判定为中档：辩论约 170 字 + 结论约 350 字 ≈ 520 字）：

### 一、反方质询（3 条）

- 【观点】"660S2 不适合人声"与 HD6 系列的中频口碑相悖，前提本身可疑
- 【事实】暖声压齿音，反而更配干冷刺的 ACG 录音；解析强会放大录音瑕疵
- 【观点】ACG 的人声向与器乐向取向相反，不能用一句"不适合"整体覆盖

### 二、正方辩护（2 条）

- 【事实】490 Pro 解析与瞬态更强、声场更开阔，复杂编曲拆得开、定位更准
- 【观点】660S2 高频偏暗、缺空气感；混合曲库下 490 Pro 不偏科、下限更高

### 三、条件式辩证结论

- 裁决：不确定（置信度：中）——你的结论可能对，但你现在给的论证前提站不住
- 成立条件：若你循环的是器乐 / 大编制 / 编曲复杂的 ACG，490 Pro 的解析与声场优势成立，选它是对的
- 不成立条件：若循环的是女声 / Vocaloid / 抒情人声，660S2 的中频情感更值，应改选 660S2
- 最重砝码：660S2 的人声口碑（反方）对 490 Pro 的器乐与混合曲库优势（正方）——这局比的不是"谁素质更高"，而是"你的曲库偏哪一边"
- 最大未知变量与反转条件：你循环最多的 ACG 子类型未知；一旦确认以人声为主，结论立即翻转为 660S2
- 建议动作：先统计近 30 天歌单里的人声 / 器乐占比；有条件就先试听一首人声向曲目，验证齿音与情感表现

## 示例二：笔记本内存 16G 加到 32G（轻档）

**用户输入**：我打算把笔记本内存从 16G 加到 32G，因为开着 Docker 再开浏览器就很卡。

**符合规范的输出**（判定为轻档：辩论约 90 字 + 结论约 160 字 ≈ 250 字，不写满）：

### 一、反方质询（2 条）

- 【事实】若卡顿主因是 CPU 或磁盘，加内存不解决问题
- 【观点】若不常开 Docker，32G 属提前消费

### 二、正方辩护（1 条）

- 【事实】Docker + 浏览器 + IDE 同开确实吃满 16G，加内存是标准解法，且成本低、完全可逆

### 三、条件式辩证结论

- 裁决：支持（置信度：中高）
- 成立条件：若多数工作日都同时开 Docker 与浏览器，且任务管理器显示内存接近跑满，加内存成立
- 不成立条件：若卡顿发生时内存占用低于 80%，瓶颈在 CPU / 磁盘，加内存是白花钱
- 最重砝码：内存峰值占用这一条实测数据（正方），压过"提前消费"的担忧——成本低且可逆
- 最大未知变量与反转条件：当前内存峰值未知；若实测峰值低于 80%，结论反转为不加
- 建议动作：先开着任务管理器用一天看内存峰值，再下单

## 对比：同一问题（示例一）、无 Skill 的朴素回答（176 字）

> 你的判断有道理。HD490 Pro 解析强、声场大，听 ACG 这种编曲复杂、信息量大的音乐确实比 HD660S2 更合适——660S2 的暖糊调音会把细节和层次糊在一起，听人声和器乐都不够通透，不太适合 ACG 的听感。而且 490 Pro 更好推，对前端要求低，用起来更省心。综合来看，如果主听 ACG，490 Pro 是更稳妥的选择，值得入手。

## 复盘要点

- 反谄媚的关键在于**反驳论证前提**（"660S2 不适合人声"与主流听感相悖），而不是顺着倾向或为反对而反对
- 无 Skill 时模型不是"不知道"反方论点，而是倾向输出让用户舒服的答案——Skill 用强制结构把模型已有的批判能力"逼"出来
- 反谄媚本质是**输出约束问题**，不是模型聪明度问题
- 辩论是给人看的**论据摘要**，结论才是**可决策的产物**：两个示例的结论都落到了"什么条件下成立 / 不成立 + 下一步先做什么"，读者只读第三节也能行动

## v4 变更说明（相对 v3）

- v3 的问题：只卡"总 ≤ 600 字"一个总闸，结构却是"反方 5 条 + 正方 3 条 + 裁判 4 行"，条目数把篇幅挤到辩论上，裁决只剩一句话——辩论长、结论短是格式设计的必然结果
- v4 的改法：
  1. 辩论条目收紧为反 2–4 条、正 1–3 条，每条一句话（≤ 25 字），同类论点必须合并
  2. 第三节从"4 行裁决"升级为**条件式辩证结论**（6 项必答：裁决 / 成立条件 / 不成立条件 / 最重砝码 / 未知变量与反转条件 / 建议动作）
  3. 篇幅改为**按争议度三档自适应**，并新增铁律"结论字数 ≥ 辩论字数""不够就砍辩论、不砍结论"
